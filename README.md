### Factory positioning
- Rids Clay is presented as a clay-product manufacturing factory.
- Current team: 10 people.
- Core activity: manufacturing and supplying traditional kulhads.


## Future Vision
In the future, Rids Clay aims to expand beyond kulhads and develop everyday household products designed to be biodegradable and more earth-conscious.
